# tsukiko

Расшифровка аудио и диктовка на macOS. Всё считается локально, whisper.cpp.

## Сборка

```sh
flutter build macos --release
./tool/sign.sh
```

Подпись обязательна: macOS привязывает выданные разрешения к ней, а ad-hoc
подпись Flutter меняется с каждой сборкой — «Универсальный доступ»
пришлось бы выдавать заново после каждой.

Для повседневной работы копируйте собранное в `/Applications`, а не
запускайте из папки сборки: `build/` сносит `flutter clean`, а вместе с
ним пропадает и приложение, которому выдано разрешение.

## Разрешения

Нужно одно: **Универсальный доступ**. Им живёт и перехват клавиш, и
вставка текста в активное окно. «Мониторинг ввода» не нужен: tsukiko
поглощает своё сочетание клавиш, а такому перехвату macOS даёт добро
только по «Универсальному доступу» — проверено, с ним одним всё работает.

При первом запуске tsukiko сам просит разрешение и появляется в списке
выключенным: остаётся щёлкнуть переключатель. Панель у строки меню
скажет, если разрешения нет, и откроет нужный раздел настроек.
Перезапускать приложение после выдачи не нужно.
