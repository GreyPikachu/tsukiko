# Tsukiko (月子)

Русская версия | [English Version](README.en.md)

**Приватная локальная расшифровка аудио и умная диктовка для macOS и Windows.**  
Все вычисления происходят исключительно на вашем компьютере: ни один байт звука или текста не передаётся в интернет.

---

## Ключевые возможности

- 🔒 **100% Offline & Приватность** — распознавание речи выполняется локально через нативные движки C/C++. Интернет не требуется.
- ⚡ **Два нативных движка «из коробки»**:
  - **Whisper.cpp** — быстрая квантованная модель OpenAI Whisper (поддерживаются модели от `tiny` до `large-v3-turbo`, аппаратное ускорение Metal на Apple Silicon и Vulkan на Windows).
  - **NeMo-Speech.cpp** — инференс моделей архитектуры Conformer (Nemotron, Parakeet) в формате GGUF для молниеносной расшифровки без Python и PyTorch.
- 🎙️ **Умная глобальная диктовка**:
  - Запуск по настраиваемому глобальному сочетанию клавиш (по умолчанию правый `⌘` на macOS или `F8` на Windows).
  - Нативный плавающий HUD с визуализацией уровня громкости, статуса записи и готовности модели.
  - Автоматическая вставка распознанного текста в активное поле любого приложения.
- 🗣️ **Голосовая активация (Hands-Free Wake Word & Close Word)**:
  - Активация записи голосом по ключевому слову (например, «Джефф» или любое своё имя) и завершение фразой («Пока», «Отбой»).
  - **Персональная калибровка под голос владельца**: акустический анализ MFCC + динамическая трансформация временной шкалы (DTW) с ансамблевым согласованием шаблонов, ограничением длительности и адаптивным шумовым порогом.
  - Полная защита от ложных срабатываний на фоновый шум и разговоры.
  - Раздельная калибровка, перекалибровка и удаление профилей для слова активации и слова завершения.
- 📚 **Словарь и контекстная подсказка (Vocabulary & Prompt Hinting)**:
  - Добавление редких профессиональных терминов, сленга, аббревиатур и имён собственных.
  - Передача приоритетных слов в `initial_prompt` Whisper с автоматическим контролем бюджета токенов.
  - Нечёткая автозамена (fuzzy replacement) на уровне пост-обработки для исправления омофонов и частых ошибок ASR.
- 🤖 **CLI-утилита, локальный API и скилл для нейросетевых агентов**:
  - Утилита командной строки `tsukiko-transcribe` для быстрой расшифровки файлов прямо из терминала или скриптов.
  - Локальный защищённый HTTP/WebSocket API (`127.0.0.1:8756`) для интеграции со сторонними программами.
  - Готовый скилл для ИИ-агентов (Claude Code, Antigravity, OpenAI Codex, OpenClaw, Hermes) — установка в один клик прямо из настроек приложения.
- 🐱 **Фирменный интерфейс**:
  - Быстрый и плавный UI на Flutter, поддерживающий тёмную и светлую темы, анимации и системные гайдлайны macOS (Apple Human Interface Guidelines) и Windows.
  - Интерактивный анимированный маскот Tsukiko (Лунный кот), чутко реагирующий на состояние записи и фоновые процессы.

## Архитектура системы

Движки распознавания поставляются внутри бандла программы и запускаются как изолированные вспомогательные процессы (IPC):

```
                        ┌──────────────────────────────────────────────┐
                        │              Tsukiko Flutter UI              │
                        │   (Главное окно, Очередь, Настройки, HUD)    │
                        └───────┬──────────────────────────────┬───────┘
                                │                              │
                MethodChannels / IPC                           │ Local HTTP / WS
                                │                              │ (127.0.0.1:8756)
        ┌───────────────────────┴────────────────────┐         │
        ▼                                            ▼         ▼
┌───────────────────┐                        ┌───────────────────────┐
│    whisper-cli    │                        │  tsukiko-transcribe   │
│  (Пакетная очередь)                        │     (CLI утилита)     │
├───────────────────┤                        └───────────────────────┘
│  whisper-server   │
│ (Потоковая диктовка)
├───────────────────┤
│    nemo-speech    │
│  (Conformer GGUF) │
└───────────────────┘
```

Подробное описание архитектуры, потоков данных и управления памятью смотрите в документе [docs/архитектура.md](docs/архитектура.md).

## Установка и запуск

### Готовые сборки

1. Перейдите на страницу **Releases**.
2. Скачайте нужный дистрибутив:
   - **macOS**: `tsukiko.dmg` (универсальный бинарник Apple Silicon M1-M4 и Intel x86_64, подписан сертификатом разработчика).
   - **Windows**: `tsukiko-setup.exe` (инсталлятор с поддержкой Vulkan GPU и CPU).

### Первый запуск на macOS

Приложение подписано сертификатом разработчика, но распространяется независимо от Mac App Store. При первом запуске macOS может показать предупреждение Gatekeeper:

1. Перетащите **tsukiko** из DMG в папку **«Программы» (`/Applications`)**.  
   > **Важно:** запуск приложения из папки «Загрузки» активирует macOS App Translocation, из-за чего выданные разрешения сбрасываются при перезапуске.
2. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите до раздела «Безопасность» и нажмите **«Открыть всё равно»**.
3. *Альтернативно (через Терминал)*:
   ```sh
   xattr -d com.apple.quarantine /Applications/tsukiko.app
   ```
4. **Разрешения**: Для глобального хоткея и автоматической вставки диктуемого текста приложению требуется разрешение **«Универсальный доступ» (Accessibility)**. Tsukiko автоматически отобразится в системном списке — достаточно включить галочку.

## Использование

### 1. Расшифровка файлов (Очередь)
- Перетащите аудио- или видеофайлы в окно программы (поддерживаются WAV, MP3, M4A, OGG, FLAC, AAC, MP4, MKV, MOV и многие другие).
- Выберите желаемую модель и язык в инспекторе справа.
- Нажмите кнопку запуска. Прогресс отображается в реальном времени.
- Готовый результат можно скопировать или экспортировать в форматах **TXT**, **Markdown**, **SRT**, **VTT** или **JSON**.

### 2. Диктовка в активное окно
- Нажмите глобальный хоткей (на macOS по умолчанию: удерживание или нажатие правого `Command`, настраивается в параметрах).
- Произнесите фразу.
- Нажмите хоткей повторно или сделайте паузу — распознанный текст автоматически напечатается в фокусном приложении (браузере, кодовом редакторе, мессенджере).

### 3. Голосовая активация (Wake Word & Close Word)
- В настройках откройте раздел **«Голосовая активация»**.
- Задайте кодовые фразы для старта и остановки записи.
- Откалибруйте каждую фразу отдельно: приложение попросит произнести слово трижды и записать одно созвучное слово, которое не должно вызывать ложного срабатывания.
- После калибровки вы можете диктовать полностью без рук: произнесите слово активации, надиктуйте мысль и произнесите слово завершения.

## Терминал и интеграция с агентами

### CLI: `tsukiko-transcribe`

Внутри приложения поставляется автономный CLI-инструмент, позволяющий расшифровывать файлы одной командой:

```sh
# На macOS:
/Applications/tsukiko.app/Contents/Helpers/tsukiko-transcribe аудио.ogg

# Проверить статус или запущенный сервис:
/Applications/tsukiko.app/Contents/Helpers/tsukiko-transcribe --status
```

Если приложение Tsukiko уже открыто, `tsukiko-transcribe` автоматически отправляет задачу в существующую очередь через локальное API, не загружая дубликат модели в оперативную память.

### Скилл для нейросетевых агентов (Claude Code, Antigravity, Codex и др.)

Tsukiko включает готовый скилл, позволяющий нейросетевым ассистентам автономно расшифровывать аудиосообщения и голосовые файлы на вашей машине без отправки файлов на внешние серверы:

- **Автоматическая установка**: Настройки → Приложение → «Скилл для нейросетей». Приложение само обнаружит установленных на вашей машине агентов и скопирует манифест.
- **Ручная установка**: документация и файлы манифеста находятся в папке [`skills/tsukiko/`](skills/tsukiko/README.md).

## Сборка из исходников

### Требования
- **Flutter SDK** (версия `>=3.12.2`)
- **CMake** (`brew install cmake` на macOS / winget/choco на Windows)
- **Xcode** (для macOS) / **Visual Studio 2022 C++** (для Windows)
- Python 3 (для вспомогательных скриптов сборки)

### Сборка под macOS

```sh
# 1. Собрать нативные движки (whisper.cpp и NeMo Conformer):
./tool/engine.sh

# 2. Установить зависимости Flutter:
flutter pub get

# 3. Собрать релизное приложение:
flutter build macos --release

# 4. Упаковать нативные движки и подписать бандл:
./tool/sign.sh

# 5. (Опционально) Создать образ DMG:
./tool/dmg.sh
```

### Сборка под Windows

```powershell
# В PowerShell от имени администратора:
.\tool\engine-win.ps1
flutter pub get
flutter build windows --release
.\tool\package-win.ps1
```
