## Сделано и проверено

**Расшифровка.** Разорвана цепочка, из-за которой повтор шёл минутами
(`-mc 0` плюс `--carry-initial-prompt`); свёртка подряд идущих повторов.
Замерено на часовой лекции: было 69 «Врезок, в голову.» подряд, стало
ноль. `docs/задача-зацикливание.md`.

**Очередь и диктовка.** Диктовка вытесняет расшифровку и та досчитывает
с той же секунды (`-ot`); пауза и продолжение руками; перестановка
очереди; недосчитанное переживает выход. `docs/задача-очередь-и-диктовка.md`.

**Свой движок.** whisper.cpp едет внутри приложения, статический
и универсальный; на Windows две сборки, Vulkan и процессорная, выбор
на месте. CUDA не нужна: 640 МБ библиотек ради одной NVIDIA против нуля
у Vulkan. `docs/задача-свой-движок.md`.

**API и скилл.** `tsukiko-transcribe` — расшифровка одной командой без
окна; местное API на 127.0.0.1 для случая, когда приложение уже
работает; скилл для нейросетевых агентов и его установка кнопкой только
тем агентам, что найдены на машине.

**Раздача.** `dmg` с перетаскиванием и своим фоном; установщик Inno
Setup со своим лицом; проверка обновлений; сборка на GitHub с кэшами.
`docs/сборка-и-выпуск.md`.

**Подпись.** С меткой времени: без неё подпись жила бы ровно до
истечения сертификата (4 июля 2027), и в этот день приложение
перестало бы запускаться у всех.

## Не сделано, но должно быть

По убыванию важности.

### 1. Сочетания по умолчанию на Windows конфликтуют сами с собой

`os_windows.dart`: hold — `ctrl+alt`, toggle — `ctrl+alt`+пробел. Первое
это **приставка** ко второму: чтобы нажать Ctrl+Alt+пробел, надо пройти
через Ctrl+Alt, и запись начинается, не дожидаясь пробела.

На macOS такого нет не случайно: там hold — `{fn, ctrl}`, toggle —
`{fn}`+пробел, и путь ко второму не проходит через первое. При переносе
взяли форму, а не смысл.

Нужно: подобрать пару, где ни одно не приставка другого, и —
важнее — **предупреждать о таком при назначении руками**. Правило общее
для обеих систем, значит и место в общем коде.

### 2. Переключатель «Быстро / Точно» убрать, дать выбор из списка

`panel_page.dart`, `_Segmented` при `canSwitchModel` — показывается,
когда моделей ровно две. Разницы систем тут нет, есть разница в числе
моделей. Хозяин просит убрать на **обеих** системах и заменить
выпадающим списком всех установленных, рядом с «Загрузить другую».
Смена — сразу, перезапуск сервера — только если правда нужен.

Там же: при смене модели окно на секунду пропадает и появляется.

### 3. `⌘Q` зашит строкой

`panel_page.dart:638` — `shortcut: '⌘Q'`. На Windows неправда. Провести
через `os.shortcutLabel`. Рядом, на строке 508, в комментарии поминается
⌘V — проверить и это место.

### 4. Запасной путь у сервера диктовки

Вычёркивание павшей сборки проверено на очереди. У сервера диктовки
(`whisper_server.waitReady`) путь другой: он поднимается долго и молчит
иначе, и павшая сборка могла ждаться до таймаута вместо немедленного
перехода на процессорную. Именно сервер диктовки и падал по журналу
сбоев Windows.

### 5. Оформление мастера установки целиком

Сделана только картинка. Вопрос хозяина «можно ли покрасить мастер
целиком» не разобран: что Inno Setup вообще позволяет менять и где
граница возможного.

### 6. ffmpeg на macOS

На Windows звук перекладывает свой `ffmpeg.exe`, на macOS — системный
`afconvert`. Это работает, но значит, что два пути расходятся: то, что
Windows умеет читать, macOS может не уметь, и наоборот. Не беда, но
стоит однажды сверить списки.

## Открытые вопросы

**Почему падал движок — не подтверждено.** Косвенно: в Prefetch лежат
обе сборки распознавателя с разницей в секунду (значит, запасной путь
сработал), а в журнале сбоев Windows есть запись об аварийном завершении
`tsukiko-dictation.exe`. Прямого доказательства нет: `Report.wer`
не читается даже с полными правами — у папки WER свои ограничения.

Остаётся один способ — текст ошибки из самого приложения. Ради этого
и делалось копирование ошибки одним нажатием.

**Один тест падает и падал всегда** — «whisper-server держит модель
и распознаёт фразу за доли секунды». Спотыкается о гонку при
параллельном запуске, поодиночке проходит. Не чинился намеренно.

**Подпись под Windows.** Доступного пути нет: Azure Artifact Signing
только для США, Канады, ЕС и Великобритании. Установщик неподписан,
SmartScreen предупреждает при первом запуске.

**Developer ID на macOS.** Сертификат у нас Apple Development. Раздавать
можно, но первый запуск на чужом Mac требует «Открыть всё равно»
в настройках безопасности. Убрать эту ступеньку может только платное
участие в Apple Developer Program.

## Что проверить руками в первую очередь

1. Поднимается ли движок. Если нет — скопировать текст ошибки из очереди
   и прислать: он теперь полный.
2. Клавиши: мгновенность, окончание записи, поведение в чужом
   полноэкранном окне.
3. Полоса уровня при тихой речи.
4. Левая колонка и панель у значка — ушла ли чернота.
5. Установка и удаление целиком, с вопросами про модели и расшифровки.
6. Не выпрыгивает ли главное окно при правке настроек — единственное
   место, где лечили симптом, не доказав причину.
