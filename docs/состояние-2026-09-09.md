## Сборка движка

Исправление подсказок лежит в `tool/prompt-context.patch`. Локальные
бинарники пересобраны с этим патчем. Скрипты macOS, Windows и CI включают
Whisper и NeMo, поэтому оба попадают в выпускаемые приложения.

## Осталось

Код по перечисленным задачам закончен. Остаются только
проверки, которые нельзя заменить локальной macOS-сборкой:

- живая проверка Windows-хоткеев, короткой диктовки, OGG с кириллицей,
  Vulkan/CPU-вариантов NeMo и оформления установщика;
- живая проверка Parakeet и Nemotron на macOS и Windows с реальными GGUF.

Другой нативный рантайм вроде sherpa-onnx сейчас не добавлен намеренно:
он дублирует уже закрытые сценарии, а его модели состоят из нескольких
ONNX-файлов и требуют отдельного формата установки. NeMo-Speech.cpp уже
даёт две разные современные семьи распознавания — Nemotron и Parakeet —
через один GGUF и один кроссплатформенный C++-рантайм.

Python для запуска готовых моделей NeMo на Windows не нужен, независимо
от размера модели. Он понадобится только разработчику для конвертации
нестандартного `.nemo` checkpoint в GGUF; готовые Nemotron и Parakeet
скачиваются уже в GGUF.
